# Browser logos

These official, full-color SVGs identify the browsers in the website's installation links.
They are bundled locally. The original artwork and colors are preserved.

- `chrome.svg`: [Google Chrome website](https://www.google.com/chrome/),
  [source SVG](https://www.google.com/chrome/static/images/chrome-logo-m100.svg).
- `firefox.svg`: [Mozilla's Protocol assets](https://github.com/mozilla/protocol-assets/blob/main/logos/firefox/browser/logo.svg),
  the Firefox Browser logo with the fox and globe.
